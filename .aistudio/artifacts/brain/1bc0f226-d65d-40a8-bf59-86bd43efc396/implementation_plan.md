# 知识工作台净化、模块化主题总览与底层交互重构方案

本方案彻底清除应用内的预置演示数据、拓扑预览卡片与右上角重置按钮，将「总览」重构为纯粹的**模块化主题画板矩阵**（每个主题模块独立呈现其节点、关系、标签与更新概览，点击进入画板后才展示画布与节点/关系创建操作），同时系统性修复底层存在的手势冲突、坐标重叠、光标插入与数据完整性等简陋问题。

## 核心决策与重点改进概览

> [!IMPORTANT]
> 本次升级聚焦「界面净化与信息分层」和「底层工程质量加固」两大核心维度：

- **彻底移除预置数据与重置入口**：清空所有硬编码的示例主题、示例节点与示例关系边；移除右上角「刷新/重置」按钮及底部的调试路径横幅，让应用回归纯净、真实的本地个人知识工作台。
- **总览页（Home）纯粹化与模块化**：总览页不再混杂画板缩略图、`+新节点`、`新建关系` 或零散节点列表，而是将**每一个主题画板呈现为独立的标准模块卡片**，模块内直观展示该主题的**节点数、关系数（含跨界连接）、标签数及高频标签、最近更新状态**；点击任意主题模块即进入对应的画板空间。
- **全面修复底层简陋实现**：解决画布单指拖拽与双指缩放手势抢占、新节点随机重叠、编辑器快捷语法无法在光标处插入、正文中 `[[双链]]` 未与图谱关系边联动、重复创建相同关系边及孤儿节点等底层缺陷。

## 1. 核心概念与信息架构重构

### 1.1 严谨的二级空间层级
- **第一层：总览（主题模块矩阵）**
  - 职责：管理与审视所有独立课题画板（Topic Boards）的宏观状态。
  - 内容：顶部汇总栏（全局主题、节点、关系、标签总量）+ 自适应网格排列的**主题画板模块卡片**。
  - 交互：新建主题、编辑/删除主题、点击主题模块直接进入该主题的「画板」空间。
- **第二层：画板与文档（进入特定主题后）**
  - 职责：在选定的主题空间内进行知识生产与拓扑连接。
  - 内容：2D 交互式画布、`+新节点`、`连线/新建关系`、自动排布（力导/辐射/环形/网格）、跨界节点显隐、以及双击/点按进入的 Markdown 节点文档编辑器。

## 2. 用户体验与视觉排版设计

### 2.1 总览页：标准化主题模块设计
- **移除冗余干扰**：移除右上角刷新按钮、移除画板拓扑雷达缩略图、移除总览页上的 `+新节点` 与 `新建关系` 按钮、移除底部节点流水账列表与沙盒路径提示。
- **主题模块卡片结构（每个主题画板一个独立模块）**：
  - **模块头部**：主题识别色条 + 主题名称 + 课题简述 + 右侧设置图标（支持重命名、改色、删除确认）。
  - **四维核心指标栅格**：在模块内部以高对比度数字网格展示该主题下的 **节点**（文档数）、**关系**（内部连线数）、**跨界**（与其他主题关联数）、**标签**（聚合标签数）。
  - **模块底部摘要**：展示该主题下排名前列的 `#标签` 胶囊与最近编辑的节点标题及更新时间；整卡点击即进入该主题画板。
- **纯净空状态引导**：首次打开或尚未创建主题时，居中呈现极简的「创建首个主题画板」引导模块，不塞入任何假数据。

### 2.2 横屏与竖屏自适应网格排版
- **总览页自适应多列矩阵**：采用自适应网格布局（最小列宽 `300.dp`）。竖屏状态下每个主题模块占满单列宽度，信息舒展清晰；横屏或平板状态下自动排布为双列或三列等高模块矩阵，充分利用横向空间。
- **画板与编辑页横竖屏适配**：
  - 画板顶部工具栏在横屏下保持单行高密度胶囊形态，底部选中节点检查器限制最大宽度（`520.dp`）并精简垂直内边距。
  - 节点详情页在「分屏」模式下，竖屏为上下对照，横屏自动切换为左源码、右渲染预览的左右双栏布局。

## 3. 底层缺陷排查与深度修复方案

### 3.1 修复画布手势抢占与缩放中心偏移
- **原问题**：画布同时挂载了独立的 `detectTransformGestures` 与 `detectDragGestures`，导致单指拖拽节点与画布平移经常相互吞噬事件，且双指缩放未以双指质心（Centroid）为锚点，缩放时画面易漂移。
- **修复方案**：重构为统一的底层多点触控手势处理器（基于 `awaitEachGesture`）：
  - 当单指按下且命中节点时，锁定为**节点拖拽模式**，实时更新节点坐标并在松手时落盘；
  - 当单指按下画布空白处时，锁定为**画布平移模式**；
  - 当检测到双指或多指触控时，平滑切换为**围绕双指质心的缩放与平移模式**，彻底消除手势冲突与跳变。

### 3.2 修复新建节点坐标随机重叠问题
- **原问题**：新建节点时使用随机数生成 `(x, y)`，经常导致新节点生成在当前视野之外或与已有节点完全重叠。
- **修复方案**：新建节点时，根据当前画布的 `panOffset` 与 `scale` 精确反算**当前屏幕视野中心的世界坐标**；若该位置附近已有节点，则沿黄金螺旋轨迹自动向外探测首个无碰撞空位，确保新节点始终清晰出现在视野中央。

### 3.3 修复 Markdown 编辑器光标插入与双链自动建边
- **原问题**：快捷语法栏只是简单将文本追加到末尾，无法在光标处插入或包裹选中文本；输入 `[[节点名]]` 仅停留在文本高亮，未与图谱关系边联动。
- **修复方案**：
  - 编辑器状态升级为 `TextFieldValue`，精准维护光标位置与选区：点击「粗体/斜体/代码」直接包裹当前选中文本或将光标置于语法符号中间；点击「双链」弹出当前知识库节点选择器，一键插入 `[[目标节点名]]`。
  - 保存文档时，自动解析正文中新增的 `[[目标节点名]]`：若目标节点已存在且尚未建立连接，自动在数据库中补齐一条 `⇢ 引用 (REFERENCES)` 语义边，真正实现「文档即节点，双链即图谱边」。

### 3.4 修复关系去重、关系编辑与级联清理
- **原问题**：同一对节点间可重复创建多条完全相同的关系边；关系边创建后无法修改类型或说明；删除主题画板时节点被强行转移导致分类混乱。
- **修复方案**：
  - **关系去重与可编辑**：同一对节点同方向同类型的边自动合并更新；在画板或详情页点击已有关系边时，支持直接修改其关系类型（关联/依赖/引用/扩展/冲突）与边签文字。
  - **严谨的主题级联管理**：删除主题画板时弹出明确确认框，支持级联清理该主题下的全部节点、关联边及对应的 `.md` 本地文件，确保数据库与文件系统零孤儿脏数据。
